## Proyecto

- App llamada `Spots`
- Objetivo: app iOS-first para descubrir lugares y planes, personalizar recomendaciones, usar la funcion `Que hacer hoy`, guardar lugares, y mas adelante armar/votar parches.
- Stack actual:
  - mobile: React Native + Expo + Expo Router
  - admin: React + Vite
  - monorepo con `apps/mobile`, `apps/admin`, `packages/shared`
- Estado actual: prototipo navegable con bastante UI/UX ya montada, datos mock, sin backend real todavia.

## Decisiones de producto importantes

- La fuente base visual de referencia es `Montserrat`
- Hay dos tipos de contenido:
  - `Lugares`
  - `En casa`
- Categorias primarias definidas:
  - Arte y cultura
  - Vida nocturna
  - Cine
  - Restaurantes
  - Eventos
  - Deporte y bienestar
  - Familiar
  - Pet friendly
  - Naturaleza y aire libre
  - Planes en casa
- Separamos:
  - categorias
  - subcategorias/tags
  - intereses del onboarding
  - moods/chips para `Que hacer hoy`
- `Que hacer hoy` no usa categorias estrictas, sino moods mas coloquiales tipo:
  - chill
  - brunch
  - tomar algo
  - bailar
  - tengo hambre
  - sin gastar mucho
  - con amigos
  - etc.
- Recomendaciones pensadas inicialmente con scoring hibrido:
  - intereses del usuario
  - popularidad
  - cercania
  - no arrancar con ML/KNN todavia
