## Notas de calidad

- Este lote esta pensado para importacion asistida, no para importacion ciega.
- Algunas cadenas tienen mas sedes activas de las que deje aqui. Solo incluí las que pude confirmar con suficiente claridad desde fuentes accesibles.
- En varios casos faltan coordenadas y redes por sede; esos campos quedaron vacios para no inventar datos.
- `Storia d’Amore`, `Karen's Pizza` y `Mister Wings` probablemente admiten una segunda pasada para completar mas sucursales y telefonos.
- `Ecoparque de la Biodiversidad` y `Saipan Airsoft` tienen operacion confirmada, pero no encontré un menu comercial equivalente, por eso ese campo queda vacio o usa sitio oficial general.
