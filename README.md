# Spots

Base inicial del proyecto `Spots`.

## Estructura

- `apps/mobile`: app mobile iOS-first en React Native + Expo
- `apps/admin`: dashboard administrativo en React
- `packages/shared`: tipos, utilidades y contratos compartidos
- `docs`: arquitectura, producto y decisiones del proyecto

## Siguientes pasos

1. Scaffold de `apps/mobile` con Expo Router.
2. Scaffold de `apps/admin` con React + Vite.
3. Integracion de Supabase para auth, data y storage.
4. Implementacion del flujo inicial de autenticacion y setup.
